# 🏋️ BMI Calculator

A responsive and interactive **BMI (Body Mass Index) Calculator** built using **HTML, CSS, and JavaScript**. This project calculates a user's BMI based on their height and weight, displays their health category, and includes a fully functional **Dark/Light Mode** for a better user experience.

---

## 🚀 Features

### 📏 BMI Calculation
- Calculates BMI using the standard formula:
  
  BMI = Weight (kg) / Height² (m²)

- Accepts:
  - Height (in centimeters)
  - Weight (in kilograms)

---

### 📊 BMI Categories

Displays the user's BMI category:

| BMI Range | Category |
|-----------|----------|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9 | Overweight |
| 30 and above | Obese |

## 💡 How to Use

1. Enter your **Height (cm)**.
2. Enter your **Weight (kg)**.
3. Click the **Calculate** button.
4. View:
   - Your BMI value
   - Your health category
5. Click the **Dark Mode** button to switch themes.

---

## 📐 BMI Formula

```
BMI = Weight (kg) / (Height × Height)
```

> Height is internally converted from centimeters to meters before calculation.
